# Asset attribution

Sealbreak's welcome screen uses the following brand artwork:

- **Sealbreak shield** — exported from the project's Figma source and already tracked at `design/figma/assets/brand/Shield.svg`.
- **OpenBao mark** — derived from `openbao/artwork/color/openbao-single-color-square.svg`. The source artwork is licensed under Creative Commons Attribution 4.0. Only the SVG display dimensions are adjusted for the inline UI asset.
- **Vault mark** — derived from HashiCorp Design System's Flight icon `packages/flight-icons/svg/vault-24.svg`. The vector geometry is unchanged; its display dimensions are adjusted and the official Vault brand color `#FFCF25` from HashiCorp's product palette is applied.

Source repositories:

- https://github.com/openbao/artwork
- https://github.com/hashicorp/design-system
