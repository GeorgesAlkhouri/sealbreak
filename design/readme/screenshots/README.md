# README screenshots

The three original PNG files are copied unchanged from `src/assets/screenshots/`
in [sealbreak-website](https://github.com/GeorgesAlkhouri/sealbreak-website/tree/a7c7c3026c4f32fb974f4aeb1f2ee3d6cfdc892b/src/assets/screenshots)
at commit `a7c7c3026c4f32fb974f4aeb1f2ee3d6cfdc892b`.

The transparent images in `framed/` include the website's rounded blue border,
offset paper layer, and shadows. Their colors and dimensions follow
[AppScreenshot.astro](https://github.com/GeorgesAlkhouri/sealbreak-website/blob/a7c7c3026c4f32fb974f4aeb1f2ee3d6cfdc892b/src/components/AppScreenshot.astro)
and the website's style variables. Exporting the frame into the image preserves
its appearance in GitHub's README renderer.

The README presents them in the same order as the website: setup, sealed,
unsealed. The original files remain available for future exports.
