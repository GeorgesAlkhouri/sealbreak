# Contributing to Sealbreak

Thank you for your interest in Sealbreak.

## License and commercial use

Sealbreak is released under the [GNU General Public License version 3](LICENSE). [COPYING.iOS](COPYING.iOS) describes the maintainer's commitment on distribution through the Apple App Store and TestFlight.

The maintainer may also offer Sealbreak under commercial or proprietary terms, including in a closed-source premium product. This does not change the GPL license granted to recipients of the open-source version.

## Code contributions

Sealbreak does not accept external code contributions yet. Because the maintainer may also license Sealbreak commercially, contributors will first need to accept a Contributor License Agreement (CLA). That agreement is still being prepared, so pull requests from people other than the maintainer are not merged for now.

Bug reports and feature requests are welcome as GitHub issues.
